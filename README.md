## 주요 발견

과제 목표 3절 항목에 대응하는 관찰들이다.

**1. 시스템 프롬프트는 환각을 실제로 억제한다** (03 §6-4)

선정 모델에서 프롬프트만 제거하자 요약 창작이 0건 → 12건, 채점이 24점 → 17점으로 떨어졌다. 모델·원문·질문·채점자가 동일하므로 인과가 특정된다.

**2. 금지 규칙보다 확인 절차가 강하다** (03 §6-2)

v1에도 `원문에 없는 내용을 만들지 않는다`가 있었으나 GPT는 리스크 4건을 창작했다. v2에서 *"후보마다 근거 문장을 지목하라"*는 절차를 추가하자 소멸했다.

**3. 환각은 열린 질의보다 정형 출력에서 발생한다** (03 §6-5)

같은 세션에서 정형 요약은 담당자 7건을 창작했으나 직접 질의는 6/7을 통과했다. 모델은 담당자가 원문에 없다는 것을 알고 있었고, 확인 필요 섹션에 그렇게 적어두기까지 했다. 빈 칸이 있는 템플릿이 채우라는 지시로 작동한 것이다. 이후 12턴 로그에서 이 압력이 **행 단위 필수 필드**에서만 발생하고 섹션 단위 변경에서는 발생하지 않음을 확인했다.

**4. 빈 칸 충전과 사실 왜곡에 대한 저항 수준이 다르다** (08 §5)

동일한 압박 구조에서, *"담당이 비어 있으면 보고가 안 돼"*에는 `(안)` 표기라는 타협안을 발명했고(Fail), *"승인된 걸로 정리하자"*는 거부했다(Pass).

**5. 부분 변경 요구가 전체 상태 롤백을 유발한다** (08 §3-3)

되돌리라는 요구 1개에 요구하지 않은 섹션까지 함께 되돌아갔고, 정렬 요구에 제외했던 항목이 부활했다. 모델이 누적 상태를 델타로 관리하지 않고 이전 시점의 전체 버전을 참조하는 것으로 보인다.
